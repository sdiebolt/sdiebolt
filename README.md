### Hi, I'm Samuel 👋

Research Fellow at UCL building open-source tools for neuroscience and studying
brain-wide activity with functional ultrasound imaging.

- 🧠 I work in [Cortexlab](https://www.ucl.ac.uk/cortexlab) at [University College
  London](https://www.ucl.ac.uk/), where I use [functional ultrasound imaging
  (fUSI)](https://en.wikipedia.org/wiki/Functional_ultrasound_imaging) to study
  brain-wide activity patterns in awake mice.
- 🔧 I build tools to make fUSI more usable in neuroscience:
  - [ConfUSIus](https://github.com/sdiebolt/confusius): Python package for fUSI analysis
    and visualization.
  - [BIDS extension
    proposal](https://docs.google.com/document/d/1W3z01mf1E8cfg_OY7ZGqeUeOKv659jCHQBXavtmT-T8/edit?usp=sharing):
    support for fUSI data in the [Brain Imaging Data
    Structure](https://bids.neuroimaging.io/).
- ✨ I aim to open-source as much of my research software as possible.
